# Above the Fold — my landing-page design experiment

I use this project to explore how a landing page can explain an offer, organize supporting information, and make the next action clear. It is a design and frontend experiment, not a measured conversion case study.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Create a production build with `npm run build`.

The site is a static frontend. Contact links open an email to me; the project does not submit or store enquiry data. The interface study is illustrative and contains no real-time AI or analytics integration.

## What I’m exploring

- A clear message hierarchy and a focused first screen.
- Scroll rhythm and restrained motion.
- Different content needs for local businesses, independent professionals, and small product teams.
- Selected project links to my live experiments and source repositories.

I avoid presenting illustrative UI as measured user behavior or conversion results. Royal Shef Hotel is a concept website; its booking controls do not process reservations.
