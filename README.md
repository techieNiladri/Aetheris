# Aetheris — my services website

I’m building this website to introduce the web development services I offer to local businesses and independent teams. The design began as an AI Studio concept; I’m adapting it into a real, first-person services page and replacing fictional claims with my own work and contact details.

## Run locally

1. Install the project dependencies with `npm install`.
2. Start the local development server with `npm run dev`.
3. Create a production build with `npm run build`.

This is a static frontend. The contact link opens an email addressed to me; the site does not collect or store form submissions.
